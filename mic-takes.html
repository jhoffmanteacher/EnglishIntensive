Mic takes

Record how Chrome's speech recogniser hears you reading a word list, so the site's listening rules can be checked against real recogniser output. Nothing is scored here and nothing is saved to the class database. Everything stays on this computer until you press Download.

Set up

Read the word as written.
Say this on purpose
Keys: Enter or N next · A again (re-record this item)

Done

The takes file holds what the recogniser returned (words, timings, confidence) and your room note — no audio. Put it in tools/mic-takes/ in the repo; the listening check replays it. The file with audio is for later experiments and is best kept on this computer.
